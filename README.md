# 🚀 My First MERN Project

A modern Full-Stack MERN application built for learning and practicing web development. This project includes secure user authentication, profile management, and a task management system with a modern glassmorphism user interface.

---

## 📖 About the Project

This project was developed using the **MERN Stack**:

- MongoDB
- Express.js
- React.js
- Node.js

The goal of this project is to learn full-stack web development by building a real-world application with authentication, CRUD operations, dashboard statistics, and responsive UI.

---

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/samindi2003/My-First-MERN.git
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```

### Install Backend

```bash
cd server
npm install
npm start
```
